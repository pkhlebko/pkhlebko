# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Personal portfolio/CV site at **khlebko.com** (GitHub Pages). Static HTML + CSS, no JS framework, no tests.

## Architecture

- `pavel_khlebko_cv_eng.md` — single source of truth for CV content. Edit this file, then run `npm run cv` to regenerate both HTML and PDF.
- `index.html` — generated from MD. Do not edit directly.
- `styles/styles.css` — all styles; uses `light-dark()` CSS function for light/dark theme toggle via OS preference
- `img/` — favicons and touch icons (generated by RealFaviconGenerator)
- `external/` — wishlist images organized by date (`YYYY-MM-DD_wishlist/`)
- `pavel_khlebko_cv_eng.pdf` — generated CV PDF
- `CNAME` — points to `khlebko.com` (GitHub Pages custom domain)

## Generation pipeline

- `npm run cv` — regenerate both HTML and PDF from `pavel_khlebko_cv_eng.md`
- `npm run cv:html` — generate `index.html` only
- `npm run cv:pdf` — generate `pavel_khlebko_cv_eng.pdf` only
- HTML generation: `scripts/generate-html.mjs` reads MD, applies masks from `scripts/masks.mjs`, converts with `marked`, fills `scripts/html-template.html`
- PDF generation: `md-to-pdf` with config at `.claude/skills/cv-pdf/md-to-pdf.config.js` and styles at `.claude/skills/cv-pdf/pdf-style.css`

## Employer name masking

HTML output masks certain employer names for the public site. PDF keeps real names. Masking rules are in `scripts/masks.mjs`.

## Formatting

Prettier is configured in `.prettierrc` — printWidth 140, proseWrap always, tabWidth 2. Run `npx prettier --write .` to format.

## Key patterns

- CSS variables in `:root` define dual light/dark palette; `light-dark()` applies them
- `html::after` pseudo-element renders the footer copyright
- Responsive breakpoints: 768px (tablet), 980px (desktop)
- PDF styling uses site's light-theme colors directly (no `light-dark()` — Puppeteer doesn't support it)
- Skills: `/cv-pdf` generates PDF, `/cv-html` generates HTML
