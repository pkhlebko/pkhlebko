This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Personal portfolio/CV site at **khlebko.com** (GitHub Pages). Static HTML + CSS, no build step, no JS framework, no tests.

## Architecture

- `index.html` — single-page CV with inline content (summary, skills, projects, career path)
- `styles/styles.css` — all styles; uses `light-dark()` CSS function for light/dark theme toggle via OS preference
- `img/` — favicons and touch icons (generated by RealFaviconGenerator)
- `external/` — wishlist images organized by date (`YYYY-MM-DD_wishlist/`)
- `cv.md` — markdown source for the CV content
- `pavel_khlebko_cv_eng.pdf` — downloadable CV PDF
- `CNAME` — points to `khlebko.com` (GitHub Pages custom domain)

## Formatting

Prettier is configured in `.prettierrc` — printWidth 140, proseWrap always, tabWidth 2. Run `npx prettier --write .` to format.

## Key patterns

- CSS variables in `:root` define dual light/dark palette; `light-dark()` applies them
- `html::after` pseudo-element renders the footer copyright
- Responsive breakpoints: 768px (tablet), 980px (desktop)
